PREREQUISITES (Do these FIRST):
================================================================================

1. CREATE GITHUB REPOSITORY:
   - Go to: https://github.com/new
   - Repository name: skilltoincome-ai
   - Description: AI-powered platform to convert skills into income
   - Visibility: Public or Private (your choice)
   - ⚠️ DO NOT check "Add a README file"
   - ⚠️ DO NOT check "Add .gitignore"
   - ⚠️ DO NOT check "Choose a license"
   - Click "Create repository"
   - COPY THE REPOSITORY URL (like: https://github.com/YOUR_USERNAME/skilltoincome-ai.git)

2. CREATE PERSONAL ACCESS TOKEN:
   - Go to: https://github.com/settings/tokens
   - Click: "Generate new token" → "Generate new token (classic)"
   - Name: SkillToIncome-AI
   - Expiration: 90 days (or your preference)
   - Scopes: Check "repo" (all checkboxes under repo)
   - Click: "Generate token" at bottom
   - ⚠️ COPY THE TOKEN IMMEDIATELY (you won't see it again!)
   - Save it somewhere safe

================================================================================
COMMANDS TO RUN (Copy and paste these):
================================================================================

# Step 1: Navigate to project directory
cd D:\skilltoincome\skilltoincome-ai

# Step 2: Initialize git repository
git init

# Step 3: Add all files to git (respecting .gitignore)
git add .

# Step 4: Create first commit
git commit -m "Initial commit: SkillToIncome AI platform with Job Board feature"

# Step 5: Add remote repository
# ⚠️ IMPORTANT: Replace YOUR_USERNAME with your actual GitHub username!
git remote add origin https://github.com/YOUR_USERNAME/skilltoincome-ai.git

# Step 6: Rename branch to main
git branch -M main

# Step 7: Push to GitHub (this will ask for credentials)
git push -u origin main

# When prompted:
# Username: [YOUR_GITHUB_USERNAME]
# Password: [PASTE_YOUR_PERSONAL_ACCESS_TOKEN_HERE]

IMPORTANT NOTES:
================================================================================

✅ Your .gitignore file is already configured correctly
✅ Sensitive files (.env, secrets) will NOT be pushed
✅ Large folders (node_modules, venv) will NOT be pushed
✅ Database files will NOT be pushed

⚠️ NEVER commit:
- .env files (contain API keys and secrets)
- Personal access tokens in code
- Passwords or credentials
- Database files with user data

If you accidentally push secrets:
1. IMMEDIATELY change/revoke the exposed secrets
2. Delete the repository
3. Create new repository and push again with correct .gitignore

NEED HELP?
================================================================================

Read the detailed guide: PUSH_TO_GITHUB_GUIDE.md

Common errors and solutions:

1. "remote origin already exists"
   → git remote remove origin
   → Then add it again

2. "Authentication failed"
   → Make sure you're using Personal Access Token, NOT password
   → Check token has "repo" scope

3. "Permission denied"
   → Check repository URL is correct
   → Verify your username in the URL
